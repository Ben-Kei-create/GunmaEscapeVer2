# 白い少女 / 感情設計バイブル

## 目的

この資料は、白い少女、ジューク、仲間会話、章ごとの感情設計、環境ストーリーテリングを今後の実装へ直接つなぐための基準書である。

主な反映先は以下。

- `js/event.js`: 白い少女イベント、章導入、儀式戦後の余韻
- `js/story.js`: 世界観の事実、フラグ管理、終盤の感情誘導
- `js/npc.js`: 仲間やNPCへの自由質問、通常会話
- `js/maps/*.js`: 環境ストーリーテリング用の掲示物、地物、演出オブジェクト
- `js/ui.js`: 静止画挿入、奉納演出、質問UI
- `js/audio.js`: 白い少女専用BGM、無音演出、章末余韻

## 1. 白い少女の正体

### 正体の定義

白い少女は、主人公の母親そのものではない。

白い少女は、**主人公の母親が遺した愛情と願いが、群馬の土地で精霊化した存在**である。

母親は主人公が幼いころに他界している。  
その死後も残り続けた「群馬にルーツを持つ息子に、この荒廃した群馬を取り戻してほしい」という祈りが、白い少女という姿を得て現れる。

### 物語上の見え方

- 真相は基本的に明かさない
- 母親という事実も明示しない
- プレイヤーには `導き手 / 救済 / 恋のようにも見える気配` として感じさせる
- だが実際の核は `愛情` と `保護` にある

### プレイヤーに与える印象

- 初見: 神秘的で少し切ない少女
- 中盤: 主人公を導く、どこか過剰に優しい存在
- 終盤: 帰る場所や愛情の象徴
- 真相に近づいた後も、答えを断言しない余白を残す

## 2. 白い少女と主人公の関係

### 事実

- ゲーム開始前に面識はない
- しかし血縁由来の想いによって、運命的につながっている
- 主人公はその存在を知らない

### 関係の着地

- 明確な恋愛にはしない
- `救済` `帰還` `人間愛` の象徴として曖昧に残す
- 外から見れば恋人のようにも見えるが、実態はもっと深い保護の感情

### 会話の原則

- 「好き」「愛している」と直接言わない
- 代わりに `帰ってきて` `ちゃんと見て` `忘れないで` `まだ歩ける` のような言い回しを使う
- 主人公の名を呼びすぎない
- 命令よりも、寄り添うような導きにする

## 3. 白い少女の台詞ルール

## 3-1. 基本トーン

- 静か
- 柔らかい
- 少しだけ古風
- 説明しすぎない
- 正解を教えるより、気づきを促す

### 台詞の長さ

- 基本は短文 1〜2文
- 長くても3文まで
- 会話イベントでも、ひとつの台詞で言い切りすぎない

### よく使う方向性

- 景色を見せる
- 気配を伝える
- 主人公の感情を先回りして受け止める
- 一本道の攻略ヒントも、物語の言葉に包んで出す

## 3-2. やってはいけないこと

- 世界設定を解説しすぎる
- 母親を連想させる直接語を使う
- 露骨な恋愛台詞を言う
- ギャグに振り切る
- 他キャラより先に真相を言い当てる

## 3-3. 台詞の機能別ルール

### 導線案内

- 例: 「あの光のほう。まだ道は切れていない」
- 例: 「風が止まっている場所に、だれかの祈りが残ってる」

### 危機の予告

- 例: 「ここは少し静かすぎる。気をつけて」
- 例: 「次は、力より呼吸を見たほうがいい」

### 励まし

- 例: 「大丈夫。ちゃんと、ここまで来てる」
- 例: 「怖くてもいいよ。止まらなければ」

### 余韻

- 例: 「この土地も、ずっと待っていたのかもしれないね」
- 例: 「終わったんじゃない。少し、静かになっただけ」

## 3-4. 白い少女イベントの使いどころ

- 初登場: 正体の説明ではなく、保護と神秘を印象づける
- 章の切れ目: 次章の感情をひとことで予告する
- 儀式戦前: 勝ち筋ではなく、向き合い方を示す
- 儀式戦後: 土地が鎮まった意味を一歩深く言う
- 終章前: 主人公が帰る意味を問い直させる

## 4. ジュークの核

### 動機

ジュークは、**群馬を守ろうとして歪んだ存在**である。

### 背景

- 才能や知能を軽んじられてきた
- 貧しさから脱する手段としてギャンブルにのめり込んだ
- その成功体験が群馬全体の歪みへつながった
- 家族や土地を守りたかったはずなのに、結果的に苦しめた

### 内面の対立

- かつて望んだ理想の群馬
- その理想を壊した現在の自分
- 殻を破ることは、自分の過去を否定することでもある

### 主人公との関係

- なりきれなかった理想像として見る
- ときに憧れ、ときに敵視する
- 反りは合わないが、根本では同じものを見ている

### 台詞の方向性

- 悪役らしく断言するが、時折本音が漏れる
- 支配者口調と自己弁護が混ざる
- 群馬を見捨てたくない気持ちが、歪んだ形でにじむ

## 5. 仲間4人の会話軸

各キャラは毎回すべてを語らず、会話のたびに必ずひとつの軸がにじむようにする。

### アカギ

- 軸: `戦略`
- 印象: 先を読む、状況を見切る、感情より段取り
- 会話の型:
  - 危険の先読み
  - 戦い方の整理
  - ぶっきらぼうな気遣い
- 補助情報:
  - 従兄弟にハルナとミョウギがいる
  - この一族の地理感覚と境界感覚は、会話の厚みに使える

### 佐藤

- 軸: `導き`
- 印象: 地図、地形、道筋、人を正しい場所へ連れていく
- 会話の型:
  - 今いる場所の読み解き
  - 道の選び方
  - 安心させる言葉

### 山川

- 軸: `継承`
- 印象: 父から受け継いだ技術や罪をどう抱えるか
- 会話の型:
  - 道具や賽の成り立ち
  - 技術の誇りと後ろめたさ
  - いまの群馬を作った責任への揺れ

### 古谷

- 軸: `理知`
- 印象: 観察、仮説、検証、冷静さ
- 会話の型:
  - 現象の分析
  - 理屈から感情へ少し遅れて追いつく
  - 父が荒廃のきっかけを作ったことへの理性的な痛み

## 6. 各章で残す感情

全体構成は 6章 + 終章 を前提にする。

| 章 | 感情 | 狙い |
| --- | --- | --- |
| 第一章 前橋関所 | 違和感 | 変な群馬ではなく、何かがおかしい群馬だと気づかせる |
| 第二章 路線の町と最初の敬意 | 敬意 | ご当地ネタを消費せず、土地の誇りとして見始めさせる |
| 第三章 赤城の運び屋たち | 郷愁 | 人や土地の過去へ感情移入させる |
| 第四章 白根と上毛学園 | 異様さ | 世界そのものの歪みと不穏を強める |
| 第五章 湯と水の境界 | 喪失 | 守りたかったものが壊れてきた痛みを見せる |
| 第六章 谷川・尾瀬・水上 | 祈り | ここまでの旅が鎮魂と再生になっていく感覚を作る |
| 終章 国境トンネル | 帰還 | 脱出だけでなく、帰ることの意味を静かに着地させる |

## 7. 環境ストーリーテリングの強化軸

今後の横展開は、以下の3軸を必ずどれかに紐づける。

### 郷土・地元愛

- 観光ポスター
- 祭りの痕跡
- 地元チェーンの名残
- 方言の貼り紙
- 誰かの寄せ書き

### 天候の特殊な変化

- 霧が局所的にだけ濃い
- 白い雨
- 熱の揺らぎ
- 無風なのに揺れるのぼり
- 水辺だけ時間帯が違って見える

### 民族学

- 土地ごとの禁忌
- 供物
- 停留所の作法
- 山や水への古い信仰
- 俗信と観光化が混ざった痕跡

## 8. リアル寄り静止画の優先順位

リアル寄りの静止画は、単なる豪華さよりも感情の結節点へ入れる。

1. 白い少女初登場
2. オープニング
3. 終章奉納
4. 儀式戦後
5. 各章ボス前後

### 挿入の原則

- 1シーンにつき1枚の印象で十分
- 画面を止める時間は長すぎない
- 表示前後の音と無音の切り替えを強く意識する
- ドット世界との断絶ではなく、記憶や啓示の差し込みとして扱う

## 9. 自由質問UIの配分

仲間やNPCへ自由質問できる場合、質問カテゴリの比率は以下を基本とする。

| 項目 | 比率 |
| --- | --- |
| 世界観 | 30% |
| 心情 | 25% |
| 攻略ヒント | 20% |
| 雑学 | 15% |
| ギャグ | 10% |

### 実装の考え方

- 毎回全部は聞けなくてよい
- キャラごとの得意カテゴリを持たせる
- 重要な世界観は `白い少女` と `村の長老格` に偏らせすぎない
- 仲間会話からも土地の理解が進むようにする

## 10. エンディングの後味

エンディング後に最優先で残す感情は以下。

- 群馬への郷土愛
- 人との絆
- 人間愛

### 避けたい着地

- ただ脱出できてよかったで終わること
- 不穏さだけを残して閉じること
- 白い少女との恋愛感情を答えとして固定すること

### 理想の余韻

- 群馬は変だった
- でも確かに人が生きていた
- 愛情は形を変えて残る
- 帰るとは、切り捨てることではなく、受け取って持ち帰ること

## 11. 今後の実装優先順位

1. 白い少女の専用会話テンプレートを `event.js` 用に作る
2. 仲間4人の自由質問カテゴリと返答パターンを `npc.js` 用に作る
3. 各章マップに `郷土愛 / 天候 / 民族学` オブジェクトを3つずつ足す
4. ジュークの中盤と終盤の台詞を、悲劇と自己否認が出る形へ再設計する
5. 終章奉納UIを、白い少女の余韻と群馬回復の実感へ接続する
