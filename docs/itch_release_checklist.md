# itch公開チェックリスト

## 配布物

- `scripts/package_itch_release.sh` で ZIP を作る
- ZIP の中身が `index.html / js / favicon.svg / site.webmanifest` だけになっていることを確認する
- `docs / output / .git / .DS_Store` が混ざっていないことを確認する

## ゲーム確認

- タイトルから `はじめから` で開始し、前橋まで正常に入れる
- `つづきから / あいことば` の導線が読める
- 前橋道具屋の価格と在庫が序盤バランス前提で表示される
- クイズが `3/3` 必須で判定される
- 通常戦と儀式戦の導入画面が読める

## itchページ文面

- 操作方法を記載する
- `同じPCならつづきから / 別PCならあいことば` を記載する
- プレイ時間の目安を記載する
- 既知の仕様や注意点があれば簡潔に記載する

## 公開前に決めること

- クレジット表記
- ライセンス表記の有無
- itchページで使うサムネイル画像
- 説明文の長文版 / 短文版
